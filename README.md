Prerequisites

Make sure the following are installed:

Node.js (LTS recommended)

npm

Deno

Git

Base44 CLI

Install the Base44 CLI globally:

npm install -g base44@latest

Install Deno by following the official installation guide:

https://docs.deno.com/runtime/getting_started/installation/

Getting Started

1. Clone the repository

git clone https://github.com/Vaibhavsp16/Social-Flow-AI.git
cd Social-Flow-AI

2. Install dependencies

npm install

3. Authenticate with Base44

base44 login

This is normally required only once per machine.

4. Link the project

base44 link

base44 link creates base44/.app.jsonc, which identifies the Base44
application. This file is intentionally excluded from Git.

5. Start the application

base44 dev

Use the frontend URL printed by base44 dev, typically:

http://localhost:5173

Important: Do not run npm run dev by itself when working with
the local Base44 backend. base44 dev starts the frontend together
with the local backend and API proxy.

Local Development

When running:

base44 dev

the following are available locally:

React/Vite frontend

Base44 API

Entities

Backend functions

Authentication

Entity data is stored in memory during local development and is
cleared whenever the local Base44 backend restarts.

The application must have been published at least once for the frontend
to load correctly with base44 dev, because the frontend retrieves
application settings from the hosted Base44 application.

Frontend Only --- Remote Backend

If you want to develop the frontend while using the deployed Base44
backend, run:

base44 dev --remote

Warning

In remote mode, API writes are made against the application's
production data. Use this mode carefully.

For normal development and testing, prefer:

base44 dev

Base44 Backend

The Base44 configuration is located at:

base44/config.jsonc

Backend functions are located under:

base44/functions/

For example:

base44/functions/generateContent/entry.ts

Entities are stored under:

base44/entities/

Git Workflow

After making changes locally:

git status
git add .
git commit -m "Describe your changes"
git push origin main

Changes pushed to the repository can then be synchronized through the
Base44 Builder.

Publishing Changes

After pushing changes to GitHub, open the Base44 dashboard:

base44 dashboard open

Publish the application from the Base44 dashboard.

Important: For a Git-integrated project, publish through the
Base44 dashboard rather than using base44 deploy. Using
base44 deploy can deploy the local working tree directly and cause
the deployed state to diverge from the Git repository.

Notes

base44/.app.jsonc is generated by base44 link and should remain
uncommitted.

Local entity data is temporary and is reset when the local backend
restarts.

Use base44 dev for normal local development.

Use base44 dev --remote only when you intentionally want to work
against the hosted backend.

Keep secrets, credentials, tokens, and other sensitive configuration
out of Git.
